# Before You Buy NYC

**Every decision carries risk. Before you buy or sell in New York, see what
actually happened after similar events in the past — with every source shown.**

> AI explores. Evidence verifies. Humans decide.

Built for the Nebius × NVIDIA Global AI Hackathon — **Best Apps and Agents** track.

## Running it locally

**Requirements:** Python 3.11+

```bash
pip install -r requirements.txt
python main.py
```

No NYC data download is required — the application queries the official
NYC Open Data API at runtime.

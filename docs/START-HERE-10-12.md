## 動作一：部署（最優先，當天做完）

**為什麼第一：** 這是唯一會卡住交件的事。評審需要一個能免費點進去的網址，
而且要撐到 12/15。今晚證明了「最後才碰部署」會出事 —— Replit 那條路整條是死的。

**先讓第一欄活在一個公開網址上就好，不用等介面做完。**

802 要先做的：`render.com` → Sign In → **Continue with GitHub**（他有帳號，
不記得密碼，八成是 GitHub 登入的）。

Render 設定：

```
New  →  Web Service  →  接 codebyyes/before-you-buy-nyc
Branch        : main
Runtime       : Python 3
Build Command : pip install -r requirements.txt
Start Command : python main.py
Instance Type : Free
```

`main.py` 已經讀 `PORT` 環境變數並綁 `0.0.0.0`，Render 不用額外設定。
先不要加 gunicorn —— 少一個會壞的東西，開發伺服器撐評審流量夠用。

**驗收：** 外部網址打開 → Region 選 Brooklyn → Confirm → 九類數字和季度表
出來。對照 `state` 檔裡那八列 2024／2025 的數字。

免費方案會休眠，第一次點進去要等約 30 秒。README 寫一句說明就好，$7 方案
的決定在 11 月底跟 Tavily 一起定。

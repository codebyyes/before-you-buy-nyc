## Replit 的三個已知事實（今晚踩到的）

1. **這個 Replit 專案是 Design 模式。** 它的 Preview 和對外網址只認它自己
   「建」出來的 app，不認 Shell 裡跑的伺服器。`python main.py` 會成功啟動，
   但 Preview 顯示 "Nothing to preview yet"，dev 網址回 **404「此次部署沒有
   可預覽的工件」**。不要再花時間找網址，那條路是死的。
2. **貼上在 Agent 對話框有效，在 Shell 無效。** 網頁終端機在 iPad 上貼不進去。
   短指令叫 802 手打，長指令走 Agent 框。
3. **Agent 會照指令執行，但指令要允許它寫檔。** 寫「不要修改任何檔案」它會
   停下來問，因為指令本身要覆寫檔案。措辭見上面那一段。
4. 跑 `python main.py` 之後那段紅字是 Flask 例行警告，不是錯誤。
5. **不要按 Publish**（會開始計費）。

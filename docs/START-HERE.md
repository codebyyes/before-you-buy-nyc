## 做事之前先知道三件事

**一、802 用 iPad，沒有電腦，不懂程式。** 他貼不了長程式碼。
流程是：你推 GitHub → 他在 Replit Agent 對話框貼一行指令拉下來。
指令原文在 `state-2026-10-11.md`。給他的步驟要像教幼稚園，一次一步。

**二、你連不到線上網址、NYC Open Data 和 Tavily。** 容器的連外白名單擋掉了。
本地只能用 stub 測，線上只能靠 802 截圖。別浪費時間試。

**三、花錢之前先跟 802 講。** 他在意錢。一題約台幣五分錢加 5–8 個 Tavily
credits，數字和理由在 `state-2026-10-11.md`。

## 七條不能動的規則

在交接文件裡。最常被「好心」改掉的三條先列在這：

1. **用「之後」不用「造成」** —— 不是文字風格，是原則
2. **AI 絕對不碰數字** —— 房價變化由程式從官方資料算
3. **空結果是正確的結果** —— 但只有「查過了、真的沒有」才算。
   查不成、額度沒了、超出可測範圍、被閘門擋下，**都不是空結果**
